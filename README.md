# SoftTransistor Homebrew tap

## Formulae

- **libinotify-kqueue**: Linux inotify API on macOS, including
  `IN_CLOSE_WRITE`. A fork of
  [libinotify-kqueue](https://github.com/libinotify-kqueue/libinotify-kqueue);
  see its [macOS notes](https://github.com/SoftTransistor/libinotify-kqueue/blob/macos-close-write/README.macos.md).

## Install

```sh
brew install softtransistor/tap/libinotify-kqueue
```

Link against it with `-linotify`.
